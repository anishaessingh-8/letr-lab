Two-Factor Between-Subjects ANOVA

Author

Dr. Anisha Singh

We continue working with readtime.csv, but now we add a second independent variable. In addition to Device (Phone, Tablet, Laptop), participants read under different lighting conditions (Blue, White, Yellow, Natural). Each participant was assigned to exactly one device type and one lighting condition, making this a 3 × 4 between-subjects factorial design (12 groups, 5 participants per group, N = 60).

Note

Why use a factorial design?

Instead of running two separate one-way ANOVAs — one for Device, one for Light — a factorial ANOVA tests both factors simultaneously. This is more efficient, uses the full sample for each test, and most importantly lets us test whether the two factors interact: does the effect of device type depend on what lighting is used? A one-way ANOVA can never answer that question.

Packages

# install.packages("psych")
# install.packages("emmeans")
# install.packages("effectsize")

library(psych)
library(emmeans)
library(effectsize)

Load and Prepare the Data

reader <- read.csv("readtime.csv")

Recoding factor levels

The variables Device and Light are stored as numbers. We need to tell R they are categorical and give them meaningful labels. The cleanest way is with factor(), which sets levels and labels in a single line — no extra packages needed.

reader$Device <- factor(reader$Device,
                        levels = 1:3,
                        labels = c("Phone", "Tablet", "Laptop"))

reader$Light  <- factor(reader$Light,
                        levels = 1:4,
                        labels = c("Blue", "White", "Yellow", "Natural"))
Tip

Why factor() instead of recode()?

The dplyr::mutate(recode(...)) approach works but requires multiple lines and the dplyr package. Using factor() with a labels argument is a base-R one-liner that does the same thing: it converts the numeric variable to a factor and attaches readable names to each level simultaneously.

Visualizing the Interaction

Before fitting the model, plot the cell means. If the lines are roughly parallel, it suggests no interaction — the effect of one factor is the same regardless of the level of the other.

interaction.plot(
  x.factor    = reader$Light,
  trace.factor = reader$Device,
  response    = reader$ReadingTime,
  fun         = mean,
  xlab        = "Lighting Condition",
  ylab        = "Mean Reading Time (ms)",
  trace.label = "Device",
  col         = c("steelblue", "darkorchid", "tomato"),
  lwd         = 2
)

The three lines track closely together and run roughly parallel across all four lighting conditions — a visual cue that Device and Light are acting independently rather than interacting.

Fitting the Model

The * operator fits both main effects and their interaction in one step.

fit2.way <- aov(ReadingTime ~ Device * Light, data = reader)
summary(fit2.way)
             Df  Sum Sq Mean Sq F value   Pr(>F)
Device        2  706968  353484   4.648  0.01428 *
Light         3 1481064  493688   6.492  0.00089 ***
Device:Light  6   21543    3591   0.047  0.99953
Residuals    48 3650203   76046
Note

Reading the factorial ANOVA table

There are three tests:

  • Device main effect: Does reading time differ by device type, averaging across all lighting conditions? F(2, 48) = 4.65, p = .014 — yes.
  • Light main effect: Does reading time differ by lighting condition, averaging across all devices? F(3, 48) = 6.49, p < .001 — yes.
  • Device × Light interaction: Does the effect of device change depending on which light is used (or vice versa)? F(6, 48) = 0.047, p = .9995 — no.

The near-zero F for the interaction (0.047) with a p-value of .9995 tells us the two factors act completely independently. The advantage of phones over tablets is essentially the same under blue light, white light, yellow light, and natural light. This is what statisticians call an additive relationship.

Overall Effect Sizes: Partial Eta Squared

eta_squared(fit2.way, partial = TRUE)
# Effect Size for ANOVA (Type I)

Parameter    | Eta2 (partial) |       95% CI
--------------------------------------------
Device       |           0.16 | [0.02, 1.00]
Light        |           0.29 | [0.10, 1.00]
Device:Light |       0.006    | [0.00, 1.00]
  • Device: partial η² = .16 — a medium-to-large effect. Device type accounts for 16% of the variance in reading time after removing Light’s contribution.
  • Light: partial η² = .29 — a large effect. Lighting condition accounts for 29% of the variance after removing Device’s contribution.
  • Interaction: partial η² < .01 — negligible. Essentially none of the variance is explained by the interaction.
Note

Why partial η² in a factorial design?

In a one-way ANOVA, η² and partial η² are identical. In a factorial design they differ: partial η² estimates each effect’s contribution relative to its own error, not relative to the total variance. This makes partial η² values from different studies comparable even when the designs have different numbers of factors.

When the Interaction Is Not Significant

Tip

The interaction guides your next step

In a factorial ANOVA, always look at the interaction first:

  • If the interaction IS significant: the main effects are misleading on their own. You must decompose the interaction using simple effects — for example, testing Device differences separately within each level of Light. The main effect averages across conditions that behave differently, which obscures what is really happening.

  • If the interaction is NOT significant (as here): the two factors act independently and additively. It is safe — and correct — to interpret the main effects directly. The effect of Device is the same across all lighting levels, so averaging across them gives an accurate picture.

Because our interaction is not significant, we proceed to main-effect post-hoc tests for Device and Light separately.

Effect Sizes for Pairwise Comparisons

Cohen’s d quantifies how large each mean difference is in standard deviation units, independent of sample size. We use the pooled model error (sigma(fit2.way)) as the standardizer.

Device pairwise d

eff_size(emmeans(fit2.way, pairwise ~ Device),
         sigma = sigma(fit2.way),
         edf   = df.residual(fit2.way))
